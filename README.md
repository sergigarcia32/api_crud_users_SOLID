API REST CRUD de Usuarios En construcción....

API REST desarrollada con Java y Spring Boot para la gestión de usuarios mediante operaciones CRUD. El proyecto está orientado a la aplicación de principios SOLID, patrones de diseño y diferentes estructuras de datos de Java.

Descripción

El proyecto permite crear, consultar y eliminar usuarios a través de una API REST.

La principal característica del proyecto es que los usuarios se almacenan en memoria utilizando diferentes estructuras de datos de Java. La estructura utilizada puede cambiarse mediante configuración sin modificar la lógica del servicio.

Actualmente se pueden utilizar estructuras como:

HashMap
TreeMap
ArrayList

El proyecto utiliza el patrón Strategy para permitir cambiar la implementación de almacenamiento de forma transparente.
